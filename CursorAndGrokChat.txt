================================================================================
- New MySQL table in the existing leadpilot DB (add to deploy/mysql_schema.sql + an idempotent

    GET  /api/config            -> all settings grouped, with defaults + current values

    PUT  /api/config            -> partial update {key: value}; returns new state
    POST /api/config/reset      -> {keys:[...]} or {group:"..."} back to default
    GET  /api/config/public     -> only "public"-scoped values the browser needs
    GET  /api/config/prompts, GET/PUT /api/config/prompts/{prompt_key}, POST .../reset
